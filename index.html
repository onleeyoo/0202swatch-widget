0202Swatch란?

자주 쓰는 컬러값,
포토샵이나 메모장에 적어두고
계속 복붙해서 쓰시는 분들 많으시죠?

저도 같은 불편함이 있어서 직접 만들었어요.

0202Swatch는 화면 어디서든 색상 값을 뽑아서
저장하고, 프로젝트별로 관리할 수 있는 위젯이에요.

이런 걸 할 수 있어요

컴퓨터에 설치하는 위젯이라
캡컷 · 파이널컷 · 프리미어 · 일러스트 등
어떤 프로그램을 쓰든 같이 쓸 수 있어요.

기능 1

어디서든 색 수집, 자동 복사

위젯을 누르거나 단축키를 누르면 확대경이 떠요.
원하는 곳을 찍는 순간 컬러값이 복사돼요.

기능 2

이미지·화면에서 색 조합 뽑기

화면을 캡처하거나 이미지를 넣으면
추천 조합 5색과 많이 쓰인 색 8개를 뽑아줘요.
바로 프로젝트에 저장할 수 있어요.

기능 3

0202 기본 컬러 조합

예능 자막, 정보·뉴스 그래픽, 브이로그 감성,
파스텔, 시네마틱, 레트로·Y2K, 무채색까지
바로 쓸 수 있는 조합이 들어 있어요.

기능 4

프로젝트별 관리 · 팀 공유

클라이언트·채널별 폴더에 색을 모아두고,
컬러칩 이미지나 공유 코드로 팀원에게 넘겨줘요.
폴더 이름까지 그대로 가요.

내보내서 0202Swatch에서 그대로 써요.

사용 방법

자주 쓰는 것부터 순서대로 모았어요.

🎯 색 뽑기

  1. 화면의 동그란 위젯 클릭
    또는 단축키 ⌥⌘C (윈도우 Ctrl+Alt+C)
  2. 확대경이 뜨면 원하는 곳 클릭
  3. 컬러값이 바로 복사돼요 · 취소는 Esc

🖼 화면 캡처·이미지로
색 조합 뽑기

  1. 화면 영역 캡처 → 원하는 영역 드래그
  2. 이미지 파일은 이미지에서 색 추출
    또는 팔레트에 끌어놓기
  3. 추천 조합을 프로젝트에 저장

✋ 드래그앤드롭으로 저장

  1. 최근 색을 프로젝트 폴더로 끌어놓기
  2. 폴더 안에서 끌면 순서 변경
  3. ⌥(Alt)를 누른 채 끌면 복제

➕ 지금 색 바로 넣기

  1. 폴더 맨 끝 점선 ＋ 클릭
  2. 현재 색이 맨 앞에 추가돼요
  3. ＋를 우클릭하면 색 고르기 창

🎨 색 미세 조정

  1. HEX 칸에 직접 입력
    (한글 자판 그대로 쳐도 OK)
  2. R / G / B 슬라이더로 조정
  3. 만든 색은 최근 색에 자동 저장

📁 프로젝트 만들고 정리

  1. ＋ 새 프로젝트 → 바로 이름 입력
  2. 폴더를 끌어서 순서 변경
  3. ⋯ 메뉴: 이름 바꾸기 · 즐겨찾기
    숨기기 · 복제 · 삭제

🗑 색 지우기

  1. 색을 우클릭 → 삭제
  2. 끌어서 아래 휴지통에 놓기
  3. 선택으로 여러 개 한 번에 삭제

🔁 팀원과 공유하기

  1. 프로젝트 ⋯ → 공유 · 내보내기
  2. 이미지로 공유: 컬러칩 이미지를
    카톡·슬랙에 바로 붙여넣기
  3. 공유 코드: 받는 사람이 불러오기로
    폴더째 그대로 가져가요

🅿️ 포토샵 스와치 연동

  1. 불러오기 → 파일 열기에서
    .ase 파일 선택
  2. 공유 · 내보내기 → ASE로 저장
  3. 포토샵·일러·AE 스와치 패널에서
    그대로 불러오기

🌐 언어 바꾸기

  1. 팔레트 제목 옆 🌐
    또는 위젯 우클릭 → 언어 / Language
  2. 한국어 · English · 日本語

⌨️ 단축키 바꾸기

  1. 위젯 우클릭 → 단축키 변경
  2. 원하는 키 조합을 누르고 저장
  3. 기본값으로 되돌리기도 가능

⚙️ 위젯 다루기

  1. 위젯을 끌어서 위치 이동
  2. 마우스를 올리면 나오는 버튼으로
    팔레트 열기
  3. 새 버전은 자동으로 받아져요
