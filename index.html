화면 어디서든
색 뽑고, 저장하고, 공유

프리미어에 없는 스와치, 따로 만들었어요. 화면에 떠 있는 위젯을 누르면 스포이드로 아무 곳에서나 색을 뽑고 HEX가 바로 복사돼요. 프로젝트별로 색을 모아두고 팀원과 공유할 수 있어요.

이런 걸 할 수 있어요

프리미어 내장 플러그인이 아니라 컴퓨터에 설치하는 위젯이라 캡컷·파이널컷·포토샵 등 어떤 프로그램을 쓰든 같이 쓸 수 있어요.

기능 1

이미지·화면에서 색 조합 뽑기

화면 영역을 캡처하거나 이미지를 넣으면 추천 조합 5색과 많이 쓰인 색 8개를 비율과 함께 뽑아줘요. 바로 프로젝트에 저장할 수 있어요.

기능 2

어디서든 색 수집, 자동 복사

위젯을 누르거나 단축키(⌥⌘C / Ctrl+Alt+C)를 누르면 확대경 스포이드가 떠요. 찍는 순간 HEX가 복사돼요.

기능 3

0202 기본 컬러 조합

예능 자막 기본, 정보·뉴스 그래픽, 브이로그 감성, 파스텔, 시네마틱·다큐, 레트로·Y2K, 무채색 프리셋이 들어 있어요.

기능 4

프로젝트별 관리 · 팀 공유

클라이언트·채널별 폴더에 색을 모아두고, 공유 코드나 파일로 함께 작업하는 사람에게 넘겨줄 수 있어요. 폴더 이름까지 그대로 가요.

전체 기능

자주 쓰는 순서대로 모았어요.

설치

공인 인증서 없이 배포하는 무료 앱이라 처음 열 때 한 번 허용이 필요해요.

맥

  1. 맥용 다운로드로 받은 dmg를 열고 0202Swatch를 Applications로 끌어다 놓아요.
  2. 응용 프로그램 폴더에서 0202Swatch를 열어요.
  3. "확인되지 않은 개발자" 창이 뜨면 시스템 설정 → 개인정보 보호 및 보안 맨 아래 그래도 열기를 눌러요.
  4. 화면 오른쪽 아래에 동그란 위젯이 생기면 끝!

윈도우

  1. 윈도우용 다운로드로 받은 exe를 실행해요.
  2. "Windows의 PC 보호" 파란 창이 뜨면 추가 정보 → 실행을 눌러요.
  3. 자동으로 설치되고 바로 실행돼요. 바탕화면과 시작 메뉴에도 생겨요.
Claude에게 설치 맡기기 (명령어)

받은 파일이 다운로드 폴더에 있을 때, 아래를 Claude에게 주고 "설치해줘"라고 하면 돼요.

# macOS
DMG="$(ls ~/Downloads/0202Swatch*-mac.dmg | tail -1)"
MNT="$(hdiutil attach -nobrowse "$DMG" | tail -1 | awk -F'\t' '{print $NF}')"
rm -rf /Applications/0202Swatch.app && cp -R "$MNT/0202Swatch.app" /Applications/
hdiutil detach "$MNT"
xattr -dr com.apple.quarantine /Applications/0202Swatch.app
open /Applications/0202Swatch.app
# Windows (PowerShell)
$f = Get-ChildItem "$env:USERPROFILE\Downloads\0202Swatch*-Windows-Setup.exe" | Select-Object -Last 1
Unblock-File $f.FullName
Start-Process $f.FullName -ArgumentList "/S" -Wait

잘 안 될 때

대부분 아래에서 해결돼요.

증상해결
dmg가 안 열려요 / "손상됨"다운로드가 덜 된 경우예요. 다시 받아주세요. 그래도 안 되면 zip을 풀어서 0202Swatch를 응용 프로그램 폴더로 옮겨주세요.
"확인되지 않은 개발자"시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기. 또는 터미널에 xattr -dr com.apple.quarantine /Applications/0202Swatch.app
위젯이 안 보여요메뉴 막대(윈도우는 작업 표시줄 오른쪽) 스포이드 아이콘 → 위젯 보이기 또는 위젯 위치 초기화
클릭해도 확대경이 안 떠요 (맥)위젯을 한 번 더 누르면 화면 캡처 방식으로 바뀌어요. 시스템 설정 → 개인정보 보호 및 보안 → 화면 기록에서 0202Swatch를 허용해주세요.
단축키가 안 돼요다른 앱이 같은 단축키를 쓰는 경우예요. 위젯 우클릭 → 단축키 변경에서 다른 조합으로 바꿔주세요.
윈도우 백신이 막아요서명 안 된 새 프로그램이라 그래요. 허용 또는 추가 정보 → 실행
그 밖의 오류팔레트 맨 아래 빨간 문구를 누르면 진단 정보가 복사돼요. 그대로 DM으로 보내주세요.
